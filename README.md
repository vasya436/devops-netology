# devops-netology
Этот репозиторий создан для курса DevOps. Здесь будут скрипты, конфигурации и примеры работы с инфраструктурой.
Файл .gitignore настроен так, чтобы не сохранять в репозитории временные файлы, кэш Terraform, состояния (*.tfstate) и локальные переопределения. Это помогает держать репозиторий чистым и не хранить чувствительные или генерируемые данные.
