# devops-netology
Этот репозиторий создан для курса DevOps. Здесь будут скрипты, конфигурации и примеры работы с инфраструктурой.
Файл .gitignore настроен так, чтобы не сохранять в репозитории временные файлы, кэш Terraform, состояния (*.tfstate) и локальные переопределения. Это помогает держать репозиторий чистым и не хранить чувствительные или генерируемые данные.

## Игнорируемые файлы (`.gitignore`)

В проекте используются файлы `.gitignore`, чтобы не сохранять в репозитории временные и генерируемые файлы. Ниже описано, какие именно файлы будут игнорироваться и что означают правила.

### Корневой `.gitignore`

Игнорируются:
- временные файлы и логи: `*.tmp`, `*.log`;
- файлы редакторов и IDE: `.idea/`, `.vscode/`, `*.swp`;
- папки с артефактами сборки: `build/`, `dist/`.

### `.gitignore` в папке `terraform/`

В этой папке игнорируются:

- `**/.terraform/*` — все файлы внутри любых папок с именем `.terraform`.  
  Символ `**` означает «в любой вложенной директории», а `*` — «любые символы» (любое имя файла).
- `*.tfstate` и `*.tfstate.*` — любые файлы с расширением `.tfstate`, а также версии этих файлов (например, `.tfstate.backup`).  
  Здесь `*` перед расширением — это «любое имя файла», а `.*` после расширения — «любое продолжение имени».
- `crash.log` и `crash.*.log` — файл `crash.log`, а также любые логи падений с шаблоном имени `crash.<что-то>.log`.  
  Точка между `crash` и `*` фиксирует, что после `crash` должна быть именно точка, а затем любое содержимое.
- `override.tf`, `override.tf.json`, `*_override.tf`, `*_override.tf.json` — файлы переопределений.  
  В шаблонах `*_override.tf` звёздочка означает «любое начало имени до `_override`».
- `.terraformrc`, `terraform.rc` — конфигурационные файлы CLI.

### Расшифровка символов в правилах `.gitignore`

- `*` (звёздочка) — означает «любое количество любых символов» (включая ноль символов).  
  Пример: `*.log` игнорирует `app.log`, `debug.log`, `server_error.log`.
- `**` (две звёздочки) — означает «в любом уровне вложенности папок».  
  Пример: `**/.terraform/*` найдёт папку `.terraform` где угодно внутри проекта.
- Точка (`.`) — обычный символ, который должен совпадать точно.  
  Пример: в шаблоне `crash.*.log` точка после `crash` обязательна: подойдут `crash.1.log`, но не `crash1.log`.
